# Remaining Gaps And Risks

## Conditional Items

- `git status --short` cannot run because this workspace is not a git repository.
- DB-backed suites still emit the known non-failing `pg` deprecation warning.

## Intentional Product Gaps

- No aggregate commission endpoint.
- No commission CSV export.
- No backfill of old commission/order rows.
- `CommissionEarning` has no `updatedAt`; response returns `updatedAt: null`.
- Legacy rows missing order-time chain snapshot remain identifiable as `legacy_missing`.

## Risk

Scope is intentionally stricter than attribution reports: it is based on commission participant lineage. This avoids leaking upline commission amounts to lower-level attribution owners, but it means a sale user will not see upline commission rows generated by their attributed order.
