# Data Quality Gates Review Note

Prompt 36 defines gates for each of the five weak findings.

Gate categories:

- minimum data completeness;
- freshness requirement;
- mapping requirement;
- sample size requirement;
- threshold source requirement;
- when confidence must be downgraded;
- when strong conclusion must be refused.

The gates preserve the advisory-only boundary by requiring downgrades when evidence is alert-label-only or lacks source rows.
